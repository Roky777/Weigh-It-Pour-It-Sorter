# Weigh It, Pour It Sorter

Browser sorting game built from the shared conveyor template.

## Levels

1. Weight or Capacity — classify ten familiar kitchen and market objects.
2. Choose the Unit — classify supplied examples by kg, g, litre, or ml.

Both levels keep four evenly spaced objects visible with continuous off-screen spawning. The first level retains the forced, skippable tutorial and progress is saved locally.
